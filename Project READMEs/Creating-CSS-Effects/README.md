# Creating Effects with CSS

A small gallery page where I practiced CSS effects on three pictures of Japan.

## What I built

- A dropdown menu that links to each picture
- **Picture 1:** a grey overlay fades in when you hover over it
- **Picture 2:** the picture zooms in when you hover over it
- **Picture 3:** a light circle "bursts" out from the center when you hover over it

## What I learned

- `transition` for smooth changes
- `transform` to zoom and move things
- `@keyframes` to make my own animations
- `z-index` to control what sits on top

## Built with

HTML and CSS

## How to view it

Download the files and open `index.html` in your browser.
