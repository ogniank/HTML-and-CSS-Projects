# The Pet Shop

A two-page website for a pet store.

## What I built

- A home page with pictures of cats, dogs, rabbits, guinea pigs, fish and reptiles
- A menu that jumps straight to each type of pet
- A dark overlay that appears when you hover over a picture
- An embedded YouTube video
- A contact page with a form and a newsletter checkbox

## What I learned

- Building a site with more than one page
- Bookmark links using `id`
- Hover effects, transitions and simple animations
- Styling forms and buttons
- Adding a favicon and meta descriptions

## Built with

HTML and CSS

## How to view it

Download the files and open `index.html` in your browser.
