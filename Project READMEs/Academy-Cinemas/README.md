# Academy Cinemas

A website for a classic movie theater.

This was my biggest Bootstrap project so far. You can browse the movies that are playing, see the show times, pick tickets and send a message.

## What I built

- A navbar with a "Now Playing" dropdown menu
- Movie cards with posters, descriptions and show time buttons
- A ticket section where you choose a movie, a time and how many tickets
- A contact form
- A footer split into sections with the Bootstrap grid
- Layouts that adjust for phones, tablets and computers

## What I learned

- How the Bootstrap grid and its classes work
- CSS variables to keep my colors and fonts in one place
- Media queries and `calc()` so text grows and shrinks with the screen
- Overriding Bootstrap's styles with my own CSS

## Built with

HTML, CSS and Bootstrap 5

## How to view it

Download the files and open `index.html` in your browser.
