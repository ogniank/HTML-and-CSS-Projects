# Ognian's Expert RC Helicopters

A one-page website about my hobby: flying remote control helicopters.

## What I built

- A home section with a short story about my hobby
- A gallery with three of my helicopters
- A flight video from YouTube
- A contact form with a dropdown and a checkbox
- A navbar with dropdown menus that jump to each section

## What I learned

- Planning a full page on my own
- Linking a separate CSS file
- Using flexbox to line up cards
- Styling form inputs with borders, spacing and rounded corners

## Built with

HTML and CSS

## How to view it

Download the files and open `one-page-website.html` in your browser.
