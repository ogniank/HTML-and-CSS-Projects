# Simple Recipes

A recipe website with easy meals for every day.

## What I built

- A navbar that sticks to the top of the screen
- A dropdown menu under "Recipes" that jumps to each recipe
- A featured recipe and six recipe cards
- An About section and a contact form
- A footer with the address and phone number

## What I learned

- How to make a dropdown menu with only CSS (no JavaScript)
- Using `:hover` and `:nth-child()` to style links
- Adding fonts from Google Fonts
- Smooth scrolling to each section

## Built with

HTML and CSS

## How to view it

Download the files and open `index.html` in your browser.
